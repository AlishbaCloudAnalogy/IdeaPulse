# IdeaPulse

**IdeaPulse** is a ServiceNow application I built for innovation and hackathon-style idea intake. Employees and community members submit ideas through a branded **Service Portal**; organizers review them in one place.

| **Submitted ideas** | `/ideapulse?id=ideapulse_submitted_ideas` |
| **Live** | https://dev390713.service-now.com/ideapulse |

## What it does

- Submit structured project ideas from a portal
- Categorize ideas by focus area
- Browse submitted ideas for triage
- Keep innovation intake on the Now Platform instead of spreadsheets

## Stack

- ServiceNow scoped application
- Service Portal (pages + widgets)
- Idea / proposal data model
- GitHub source control

## Deploy

1. ServiceNow Studio → **Create** → **Import app**
2. This repository, branch `main`
3. Open `/ideapulse` and submit a sample idea
